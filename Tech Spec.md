# Техническое задание

## Функциональные требования

### Авторизация и регистрация пользователя

1. Регистрация
    1. При регистрации, пользователь должен заполнить обязательные поля, такие как email, username, password. Если какое-либо поле не заполнено, бэкенд должен вернуть ошибку валидации с кодом 422.
    2. Если все поля заполнены корректно, и в базе нет дубликатов, данные пользователя должны быть успешно сохранены. После успшеного сохранения, бэкенд должен вернуть успешный ответ с кодом 204.
    3. Если в базе уже существуют такие username или email, бэкенд должен вернуть статус код 409 с описание того, какое поле является дубликатом
2. Авторизация
    1. При авторизации если все данные введены верно, бэкенд должен вернуть token и refresh_token со статус кодом 200
    2. Если при авторизации введены неверные логин или пароль, бэкенд должен вернуть ошибку со статус кодом 401
    3. При запросе обновления токена при корректном refresh_token бэкенд должен вернуть успешный ответ, содержащий token и refresh_token со статус кодом 200
