# Техническое задание

## Функциональные требования

### Авторизация и регистрация пользователя

1. Регистрация
    1. При регистрации, пользователь должен заполнить обязательные поля, такие как email, username, password. Если какое-либо поле не заполнено, бэкенд должен вернуть ошибку валидации с кодом 422.
    2. Если все поля заполнены корректно, и в базе нет дубликатов, данные пользователя должны быть успешно сохранены. После успшеного сохранения, бэкенд должен вернуть успешный ответ с кодом 204.
    3. Если в базе уже существуют такие username или email, бэкенд должен вернуть код 409 с описанием того, какое поле является дубликатом.
2. Авторизация
    1. При авторизации если все данные введены верно, бэкенд должен вернуть token и refresh_token с кодом 200.
    2. Если при авторизации введены неверные логин или пароль, бэкенд должен вернуть ошибку с кодом 401.
    3. При запросе обновления токена при корректном refresh_token бэкенд должен вернуть успешный ответ, содержащий token и refresh_token с кодом 200.

### Профиль
1. Без профиля у пользователя не должно быть возможности пользоваться следующими функциями системы: просмотр профилей других пользователей, добавление других пользователей в друзья, создание и ведение чата с другими пользователями.
2. Создание профиля
    1. Пользователь может иметь только один профиль. В случае, если пользователь имеет профиль и пытается создать ещё один профиль бэкенд должен отдавать информативную ошибку о том, что пользователь уже имеет профиль с кодом 400.
    2. Для создания профиля обязательно должны быть заполнены следующие поля: имя, фамилия. Если какое-либо из этих полей приходит пустым, бэкенд должен возвращать ошибку валидации с кодом 422.
    3. Если все поля заполнены корректно и у пользователя нет профиля, то система должна создать его профиль и вернуть ответ с кодом 204.
3. Редактирование профиля
    1. Пользовать должен иметь возможность редактировать все поля в профиле.
    2. Если после редактирования какое-либо из обязательных полей приходит пустым, система должна возвращать ошибку валидации с кодом 422.
    3. Если все обязательные поля заполнены корректно, и система успешно обновила профиль, она должна вернуть ответ с кодом 200 и телом ответа, содержащее обновлённый объект профиля.
4. Удаление профиля
    1. Пользователь должен иметь возможность удалять профиль.
